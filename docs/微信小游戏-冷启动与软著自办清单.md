**做：**

## 1. 冷启动策略：通过邀请加入

### 1.1 一句话

> 不做「等人匹配」冷启动；**第一批用户全靠邀请链路进房**，用 1 万积分礼包驱动老带新，用好友房保证能凑开 2 人 + 1 AI。



### 1.2 冷启动漏斗

```
种子用户（团队/熟人）开好友房
  → 分享邀请卡 / 带参链接（「对方得 1 万积分」）
  → 新用户微信登录 + 首登建号（归因到邀请人）
  → 被邀方到账 10,000 积分；邀请方到账拉新奖（建议 500–1,000）
  → 两人入座 + AI 补位开局
  → 终局揭晓卡再分享 → 下一轮邀请
  → 积分不足 → 看广告 / 充值 / 再邀 1 人
```



### 1.3 产品必须先上的能力（冷启动最小集）


| 优先级 | 能力                  | 说明                          |
| --- | ------------------- | --------------------------- |
| P0  | 微信登录 + 账户积分         | 服务端发货，客户端不自增                |
| P0  | 邀请归因链接 / 小程序卡片      | 1 名新用户绑定邀请人                 |
| P0  | 被邀方 **10,000** 积分礼包 | 只发一次；与自然量 500 互斥            |
| P0  | 好友房 + AI 补位         | 2 人即可开打，解决三人难凑              |
| P0  | 简化对局可完赛             | 走子扣费、吃子、破产、终局揭 AI（可先砍观战/回放） |
| P1  | 邀请方拉新奖励             | 建议每成功 1 人 500–1,000，设日/周上限  |
| P1  | 积分不足补给面板            | 看广告 → 充值 → 再邀（顺序可配）         |
| P2  | 终局揭晓分享卡             | 强化二次裂变文案                    |


详细数值与防刷见 PRD **§3.5**。

### 1.4 种子期运营动作（0→100 人量级）

1. 准备 20–50 个种子微信号（同事、棋友、狼人杀群）。
2. 每人发「邀请话术 + 小程序卡」：强调 **「你点进来就送 1 万积分」**。
3. 固定每晚开 2～3 桌「导演房」，保证新用户进房立刻有人带打。
4. 统计：邀请点击 → 注册 → 完赛 → 再邀请；卡在哪一环就改文案或礼包展示。
5. 明确不靠公开匹配大厅撑前两周（大厅可后期再开）。



### 1.5 防刷（冷启动也要做最低限度）

- 新号、设备 / 实名异常集群不发 1 万档或降级为自然量 500。
- 邀请方与被邀方不能同一实名薅羊毛。
- 邀请、广告奖励一律 **服务端发货**。
- 文案只用「邀请得积分」，禁用「提现 / 赚现金」。

## 3. 软著自己办：要花多少钱

> 指 **计算机软件著作权登记**，自己在中国版权保护中心（或地方代收渠道）网申。  
> **官费以版权中心当期公示为准**；下表为常见量级，便于做预算。  
> 勾选进度见 **§2.2**；材料细节见下。



### 3.1 费用区间（自办）


| 项目                | 预估                   | 说明                      |
| ----------------- | -------------------- | ----------------------- |
| 登记官费              | **约 0～300 元 / 件**    | 近年政策有调整（含减免阶段）；下单前看官网价目 |
| 材料打印 / 刻盘（若仍要求纸质） | **0～50 元**           | 多数已电子化，可能为 0            |
| 加急（可选）            | **数百～数千元**           | 自办一般不需要；等普通审即可          |
| 代理代办（本次不做）        | （参考）500～2,000+ 元     | 本文按自办，不计入必花项            |
| **自办现金合计**        | **建议预算预留 300～500 元** | 覆盖官费波动 + 杂费；主体是时间不是钱    |


**结论：** 软著自办 **钱很少**（通常几百元内）；真正成本是 **准备材料 + 等证 1～2 个月（含补正）**。

### 3.2 自己要准备的材料（清单）


| 状态  | 材料              | 要点                               |
| --- | --------------- | -------------------------------- |
| ☐   | 软件全称 / 简称 / 版本号 | 与小游戏对外名称尽量一致或可说明关联               |
| ☐   | 权利人             | **企业**（棋牌类目通常要公司主体）              |
| ☐   | 开发完成日期、首次发表日期   | 按实际填写                            |
| ☐   | 源代码鉴别材料         | 一般前后各连续 30 页（或按当期要求页数），页眉带软件名与页码 |
| ☐   | 操作说明 / 设计说明书    | 若干页；写清「三国棋局 / 积分版小游戏」功能模块即可      |
| ☐   | 营业执照等主体材料       | 按网申上传要求                          |




### 3.3 建议时间线（与研发并行）


| 周次       | 动作                               |
| -------- | -------------------------------- |
| 第 1 周    | 确认公司主体；起软件名；拉取可提交的源码片段与说明书草稿     |
| 第 1～2 周  | 网申提交软著                           |
| 并行       | 微信小游戏认证、棋牌类目预沟通（是否还要版号另确认）——见 §2 |
| 约 1～2 月后 | 拿证；归入 §2.6 提审材料包                 |


> 版号是否硬性要求：**必须以微信棋牌类目当期规则 + 法务确认为准**；本文默认 **软著自办**，版号单列在 §2.2。
