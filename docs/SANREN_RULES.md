# 三人象棋规则口径

适用于前端、`packages/shared` 和链上 `GameTable`。三处共用同一份地图数据（落点、线、格），由照片描图生成。本文只定规则；具体有多少个点、哪条线连到哪里，以地图数据为准。

## 1. 棋盘结构

- **三营。** 红营在左上，绿营在右上，黑营在下方。三营形状相同，互成 120°。
- **每营是半张象棋盘。**
  - 9 条纵线 f0–f8，f4 是将所在的中线。
  - 5 条横线 r0–r4，r0 是底线，r4 最靠中心。横线是弧线。
  - r4 为朝向中宫的河沿线（全宽 f0–f8）；隔位兵都可先进一步到 r4。
- **九宫。** f3–f5 × r0–r2，带两条斜线。
- **营间有河。** 三营扇区横向收窄（`fileScale`），边线内收（`edgeTaper`）按 rank 加权（底线松、河沿紧），邻营**不相接、不共点、无外圈桥**；底线车马不叠、河角不交叉。
- **过河走中宫（五口）。** 离开本营 → 别营经中宫。每营河沿线入口：
  - **左边兵** f0:r4 → 角点 K → 内点 I → 中点 X → 中宫（向心干道，不挤辅路）
  - **左辅** f2:r4 → 左须 → 门
  - **中路** f4:r4 → 门 → 中宫
  - **右辅** f6:r4 → 右须 → 门
  - **右边兵** f8:r4 → 邻角 K → 内点 → 中点 → 中宫
  兵过河前只能沿本文件前进，不能横走。中宫内边兵可沿向心干道前进。

## 2. 子力与初始摆法

每方 16 子，摆法按照片：

| 位置 | 棋子 |
|------|------|
| r0，f0–f8 | 车 马 象 士 将 士 象 马 车 |
| r2，f1 和 f7 | 炮 |
| r3，f0 f2 f4 f6 f8 | 兵（标准隔位；营间有河，外角不与邻营相连） |

棋子上的字：红营是帅和兵，黑营是将和卒，绿营是王和丁。其余棋子三营同名。

## 3. 走法

先定义几个词：

- **线**：地图上一条有序的点链，包括纵线、横线、过渡区连线和中宫连线。
- **相邻**：同一条线上紧挨着的两个点。
- **格**：四个两两相邻的点围成的小块。

各棋子走法：

- **车**：沿任意一条线走任意步，中间不能有子。
- **炮**：走法同车。吃子时，和目标之间要恰好隔一子。
- **马**：先沿线走一步到马腿点，马腿点必须是空的；再走到一个包含马腿点、但不包含出发点的格的对角点。这就是日字，蹩腿有效，可以跨营。
- **象**：只能在本营走。按本营坐标走 (±2, ±2)，象眼 (±1, ±1) 必须是空的。
- **士**：只能在本营九宫里，沿斜线走一步。
- **将**：只能在本营九宫里，沿线走一步。不做将帅对面的规则。
- **兵**：每次走一步，不能后退。
  - 在本营里：沿本营纵线朝中心前进；**过河前不能横走**。
  - **营间是河，外角没有直连邻营的路**。
  - 过河五口（f0 / f2 / f4 / f6 / f8 的 r4）：一步踏进中宫图（角 / 须 / 门）。离开本营后可前进或横走（别营里「前进」朝那一营底线，「横走」沿那一营横线）。
  - 在中宫里，前进是离开自己的门，或沿向心干道靠近盘心；横走是和自己的门保持同样步数。边兵进角后优先：角→内点→中点→中宫，再出环岛。

## 4. 经济规则

只换距离的算法，其余不变：

- 油费 = (BASE_FEE + 步数 × DIST_UNIT) × 棋子系数。
  - 车、炮、将、兵的步数是沿线走过的点数。
  - 马、象按 2 步算，士按 1 步算。
- 吃子得分、被吃扣分、吃将夺一半质押、破产、70/20/10 结算都不变。
- Slash 的证据仍是“攻方吃掉盟友的士”。
- 被击败一方的棋子留在盘上当障碍，和现在的合约一致。

## 5. 座位与行棋顺序

| seat | 营 | 位置 | 演示中的角色 |
|------|----|------|------|
| 0 | 红营 | 左上 | 人类 A，被背刺的受害方 |
| 1 | 黑营 | 下方 | 人类 B |
| 2 | 绿营 | 右上 | AI 卧底 |

行棋顺序：红 → 黑 → 绿。

## 6. 照片没画出来的约定

- **营和中宫的连接（已确认）。** 每营 f4 的 r4 点和朝向它的中宫门相连，这条连线算作 f4 纵线的延长。
- **线怎么穿过中宫。** 只认照片里画出来的线。一条线在交叉点处如果继续往同一方向走，就算同一条线，车、炮可以一路走过去。
- **营间无外角过渡落点。** 过河与跨营一律经中宫判定兵的前进/横走。
- **演示长度。** 绿马跨营背刺手数可能较长；Demo 剧本可单独前移绿马，正式开局马归位。
