# 三国棋局 — 消费版产品需求文档（微信小游戏 · 积分版）

| 字段 | 内容 |
|------|------|
| 产品中文名 | 三国棋局 |
| 产品英文名 | Shadow Xiangqi（消费版） |
| 版本 | **消费版 v1.0** |
| 文档日期 | 2026-10-11（Asia/Shanghai） |
| 主平台 | **微信小游戏**（首选）；原生 App 可选延期 |
| 受众 | 喜欢狼人杀 / Among Us 式社交推理的休闲玩家 + 轻度象棋爱好者 |
| 经济模型 | **纯积分 + 微信虚拟支付**；无链、无 Token、无钱包 |
| 文档性质 | 消费向 PRD（由黑客松链上原型玩法「去链化」改编） |

**一句话定位：**  
三人象棋桌上藏着一个 AI 卧底——每步烧积分、吃子赚积分；用诚意积分秘密结盟，背刺罚没；终局揭晓谁是 AI。

## 1. 一句话定位 & 会不会火

### 1.1 定位（电梯稿）

> **象棋桌 + 狼人杀。**  
> 三人对局，必有一座是 AI 卧底；走子要花积分，结盟要押诚意积分，背刺被罚；省油（省积分）和氪金两条打法都能赢。

### 1.2 会不会火——诚实判断

| 维度 | 判断 | 说明 |
|------|------|------|
| **病毒潜力** | **中高** | 「谁是 AI」揭晓 + 背刺罚没 + 好友局吐槽，天然适合微信群分享与观战截图；狼人杀用户池大，象棋认知门槛在国内低 |
| **差异化** | **高** | 市面「象棋小游戏」多为双人对战/残局；「社交推理棋类」几乎空白 |
| **上瘾点** | **中高** | 每步都是性价比题；鲸吞远途车 vs 预算党短途缠斗，复盘有梗 |
| **主要风险** | 见下 | 不吹「稳火」，需正视获客与合规 |

**主要风险（必须写进决策）：**

1. **棋牌类目审核**：微信小游戏棋牌类目门槛高，需企业主体 + 版号/相关资质路径清晰，周期可能拖 1–3 个月。
2. **匹配冷启动**：三人局比双人更难凑桌；MVP 必须强依赖「2 人 + 1 AI」与好友房。
3. **象棋深度 vs 休闲**：规则过重流失狼人杀用户；过浅流失棋迷——必须坚持「可执行简化三人象棋」，不教百科。
4. **积分经济崩盘**：若走子费/吃子收益调参失误，会出现「只吃不走」或「一步破产」；需运营热修数值表。
5. **AI 太弱/太强**：卧底一眼假或永远碾压，都会杀死「猜谁是 AI」的乐趣。
6. **付费反感**：若感觉「不氪不能赢」，预算党会弃坑——**合法着法永远优先于氪金**，预算路径必须能完整打完一局。

**结论（给决策者）：**  
值得做微信小游戏 MVP 验证；**不是稳赚品类，但是有清晰传播钩子的中高风险中高回报社交轻竞技。** 成败取决于：冷启动凑桌、数值调参、审核过类目、首月留存是否站上 20% D1。

## 2. 核心玩法循环（无链）

### 2.1 角色

| 角色 | 人数 | 说明 |
|------|------|------|
| 人类玩家 | 2 | 微信登录；不知谁是 AI |
| AI 卧底 | 1 | 系统指定一座；目标：存活、逼人类互烧积分、收割积分、适时背刺 |
| 观战者 | 0–N | 看公开棋盘与积分；不见盟约当事人与 AI 身份 |

**铁律：** 非法着法永远不允许（合法格高亮；非法格不出现，更不能靠氪金解锁非法着）。

### 2.2 主循环

```
匹配/好友房入座 → 各扣「入座押金积分」+ 注入「作战积分」
    → 系统私下指定恰好 1 个 AI 座
    → 公开棋盘行棋：点己子 → 合法格显示预估走子费 → 确认扣费
    → 吃子：进攻方赚积分；被吃方丢部分积分 + 付捕获罚金
    → 可选：秘密求援（私聊 + 锁诚意积分）→ 对方接受 → 盟约生效
    → 可选：疏火贿赂 BUY_PEACE（花积分买 N 步停火）
    → 背刺/违约 → 受害方发起挑战 → 诚意积分罚没给受害方
    → 出局（将死 / 破产付不起最低合法着）→ 击败方吞对方积分
    → 终局：揭 AI + 动机摘要 + 结算排名与赛季分
```

### 2.3 开局

1. 座位固定 **A / B / C**（三角三营简化布局）。
2. 入座：扣 `seatStake`（押金积分，终局可退/按规则分成）+ 记入 `playBalance`（作战积分）。
3. AI 座对人类 UI **不显示**；观战也不显示。
4. 模式：
   - **好友房**：房主邀请，可指定「必须含 1 AI」或「满 3 真人再开」（真人局为延期）。
   - **快速匹配**：优先 2 人 + 1 AI；超时则 AI 补位开局。

### 2.4 对局公开 / 私有信息

| 公开 | 私有 |
|------|------|
| 棋盘、行棋方、已走棋谱、各座作战积分与记分牌、公开事件（有人结盟了、有人被罚没——可不露座位） | AI 身份、盟约明文、求援私聊、未公开的贿赂当事人 |

### 2.5 走子与破产

- **走子费公式（积分版）：**

```text
distance = chebyshev(from, to)   // max(|Δx|, |Δy|)
moveFee  = (baseFee + distance × distUnit) × pieceMult[piece]
```

- 合法格旁实时显示预估 `moveFee`；余额不足的合法格灰显并提示「作战积分不足」。
- **破产唯一口径：** 当前座 `playBalance < 最低可负担合法着法费用` → **立即自动认输出局**。押金不得垫走子费。
- 超时未走：扣 `timeoutPenalty` 后再跑破产检查；否则跳过本步（弃权一步）。

### 2.6 吃子 / 击败

| 事件 | 结算 |
|------|------|
| 吃子 | 进攻方 +`piecePoints`；被吃方 −⌊对应分×0.5⌋ 且付 `capturePenalty`；进攻方仍付本次 `moveFee` |
| 击败（将死/破产） | 击败方吞败方全部记分牌积分；败方押金 40%→击败方作战积分，60%→本局奖池 |
| 终局 | 奖池按 70% 胜者 / 20% 积分第二 / 10% 系统；胜者押金全退；剩余作战积分退回账户 |

### 2.7 盟约与背刺（社交推理核心）

**状态机：** `待接受诚意 → 接受后盟约生效 | 拒绝/超时退诚意`；`生效 → 履约退还 | 违约罚没`。

**MVP 条款（≥2 条可选）：**

1. `NO_CAPTURE_ADVISOR`：不吃对方士  
2. `MUTUAL_NON_CHECK`：互不将军（N 步内）  
3. （可选）`NO_EXPOSE_BEFORE_END`：终局前不公开指控对方是 AI  

**隐私档（消费版简化，无 ZK）：**

- 激活时第三方只见「桌上有人结盟了」，不见是谁。  
- 罚没/终局时揭示当事人（戏剧高潮需要）。  

**AI 必做策略（P0）：**

| 策略 | 要求 |
|------|------|
| 假诚意 | 盟约履约约 8–12 手后吃盟友关键子或攻帅 |
| 油费刺客 | 用远途车威胁逼人类烧作战积分 |
| 启发式走子 | 吃子净分 − λ·走子费 − 被将军惩罚；能完局即可 |

### 2.8 胜负（可执行简化）

1. 将/帅被吃或无法解将 → 该阵营出局。  
2. 破产 → 出局。  
3. 仅剩一方未出局 → 该方胜。  
4. 达 `maxPlies = 80` → 记分牌 + 子力价值决胜。  
5. 规则细节冲突 → 以本 PRD 简化为准（inspired by 三人象棋，不做规则百科）。

### 2.9 默认数值表（积分版 · 可热修）

> 单位一律为「积分」。下表为 v1.0 建议默认值，运营可后台覆盖。

| 参数 | 建议值 | 备注 |
|------|--------|------|
| `seatStake` | 100 | 入座押金 |
| `playBalanceInitial` | 200 | 开局作战积分 |
| `baseFee` | 1 | 走子基础费 |
| `distUnit` | 0.5 / 格 | Chebyshev 距离 |
| `pieceMult` | 车 2.0 / 马炮 1.5 / 象士 1.2 / 将 1.0 / 卒 0.6 | |
| `piecePoints` | 卒 10 / 士象 30 / 马炮 50 / 车 100 | 吃子记分 |
| `capturePenalty` | 分值 × 0.1 | 被吃方额外扣作战积分 |
| `earnestBond` | 10 | 单次求援诚意积分 |
| `bondPerClause` | 15 | 每条款保证金 |
| `maxActiveCovenantsPerSeat` | 1（默认） | 鲸可升至并行 Pending 3 |
| `BUY_PEACE` 金额 | 15–50 | 买 3 步停火；对方可拒 |
| `timeoutPenalty` | 3 | |
| `maxPlies` | 80 | |
| 新用户赠送 | 500 积分 | 足够打完约 2 局 |

**口播示例：** 卒走 1 格约 **0.9 积分**；车走 5 格约 **7 积分**；马 distance=2 约 **3 积分**。

## 3. 积分经济与氪金 / 性价比

### 3.1 单一账本（相对链上版的简化）

消费版用 **账户积分** 统一承载：

| 概念 | 含义 |
|------|------|
| 账户积分 | 可跨局携带；充值/任务/赛季奖励获得 |
| 入座押金 `seatStake` | 本局锁定，终局按规则退还或分成 |
| 作战积分 `playBalance` | 本局走子/诚意/贿赂消耗池 |
| 记分牌 Points | 本局吃子/击败得分，影响终局排名与奖池 |

UI 始终并排：`作战积分 | 记分牌 | 押金锁定中 | 账户余额`。

### 3.2 积分从哪来 / 到哪去

**来源：**

- 每日登录、对局任务、成就（免费）  
- 分享邀请好友（拉新）  
- 微信虚拟支付充值礼包（人民币 → 积分）  
- 赛季结算、活动赠送  

**消耗：**

- 入座押金与作战积分（对局内）  
- 走子费、捕获罚金、超时罚金  
- 诚意积分、盟约保证金、BUY_PEACE  
- （可选延期）外观、表情、观战弹幕特效——**不卖战力外挂**  

**重要合规口径：** 积分为游戏内道具，**不可兑换现金、不可玩家间转赠现金化**；仅用于对局与装饰。

### 3.3 双路径：鲸 vs 预算党

| 路径 | 核心打法 | 经济动作 |
|------|----------|----------|
| **氪金（Whale）** | 积分多 → 敢走贵着（远途车、连动压迫）；用积分买节奏 | 中盘补给作战积分；多线诚意求援；BUY_PEACE；代付盟友一步走子费 |
| **性价比（Budget）** | 压低每步 `moveFee`：短距、低系数；逼对手破产；记分/油耗比以小博大 | 不充值也能靠每日赠送打完；破产规则仍生效 |

**氪金具体玩法（可调）：**

1. **多线诚意求援：** 默认每座同时 1 笔 Pending；作战积分 ≥ 阈值（建议 300）可并行最多 3 笔，多头试探。  
2. **疏火贿赂 `BUY_PEACE`：** 花 15–50 积分买对方 **3 步**不攻己方/不吃约定子；可拒；接受后违约走罚没。  
3. **代付盟友一步走子费：** 活跃盟约内可代付；每局上限 5 次或合计 50 积分。  
4. **中盘补给：** 从账户积分转入本局 `playBalance`（不改押金）。

**预算党反制：**

- 收钱背刺（收诚意/贿赂后违约 → 罚没）  
- 拒贿/超时退款（可不暴露拒方）  
- 省油缠斗逼破产  

**产品铁律：**

> **合法走子永远优先于烧积分。**  
> 不存在「花积分走非法着」。UI 提供「省油推荐」标出低费用/高记分效率候选。

### 3.4 建议充值档位（微信虚拟支付）

| 档位 | 价格（元） | 积分 | 备注 |
|------|------------|------|------|
| 尝鲜 | 6 | 600 | 首充双倍一次 |
| 常玩 | 18 | 2,000 | |
| 进阶 | 45 | 5,500 | 多送表情包 |
| 土豪 | 98 | 13,000 | 赛季头像框 |

不卖「必胜礼包」；可卖「补给包」（作战积分）与外观。付费战力仅体现在「敢走贵着 / 多结盟试探」，**不改变棋规合法性**。

## 4. 社交与传播

### 4.1 分享钩子（微信原生）

| 钩子 | 触发 | 内容 |
|------|------|------|
| 终局揭晓卡 | 每局结束 | 「本局 AI 是 X！背刺了 N 次」+ 一键分享好友/群 |
| 背刺名场面 | 罚没发生 | 短动图/棋谱截图 + 文案「盟友翻车了」 |
| 好友房链接 | 房主 | 小程序卡片「来一局三国棋局，桌上有卧底」 |
| 观战邀请 | 对局中 | 「来看我们互相背刺」 |
| 邀请有礼 | 新用户经分享注册 | 双方各得积分（防刷：设备/实名风控） |

### 4.2 观战

- 公开棋盘实时同步；可见作战积分与记分牌。  
- 不可见：AI 身份、盟约明文、求援私聊。  
- 弹幕：预设快捷吐槽（「这车好贵」「要背刺了吧」）减少审核风险。  
- MVP：好友房观战；匹配局观战可延期。

### 4.3 回放

- 整局棋谱 + 经济事件时间轴（走子费、吃子、诚意、罚没、补给）。  
- 终局可跳转到「AI 动机摘要」节点。  
- 支持生成 15 秒精华短视频素材（系统自动剪背刺+揭晓），便于发朋友圈/视频号（P1）。

### 4.4 好友局

- 2–3 人房；不足 AI 补位。  
- 房主可设：积分倍率（练习房 0.5× / 标准 1×）、是否强制含 AI、回合时限。  
- 练习房不进排位、少消耗，降低劝退。

### 4.5 传播飞轮（预期）

```
好友房开黑 → 背刺名场面分享 → 围观进房 → 自己开房
         ↘ 终局揭 AI 卡片 → 群聊讨论「我猜对了」→ 次日回流
```

## 5. MVP 范围 vs 延期

### 5.1 MVP（必须上线验证）

| 模块 | 内容 |
|------|------|
| 账号 | 微信登录、基础资料、账户积分 |

| 经济 | 押金/作战积分/记分牌；吃子；击败吞分；破产；中盘补给 |
| 社交欺骗 | 诚意求援、盟约（≥2 条款）、背刺罚没、BUY_PEACE |

| 社交 | 好友房、分享卡片、基础观战、整局回放 |

| 合规基础 | 隐私政策、用户协议、防沉迷/实名（按微信要求）、棋牌类目材料 |

### 5.2 明确延期（不进首发）

- 3 真人匹配大厅与排位赛季完整体系  
- 谣言商店、公开指控投票 UI  
- 完整冷门棋规 / 残局库 / 教学模式百科  
- 原生 iOS/Android App  
- 直播 SDK、视频号自动投稿、公会系统  
- 复杂大模型实时对话 AI（成本高；MVP 用规则+脚本动机日志）  
- 跨服万人观战、竞猜（合规敏感，谨慎评估后再做）

### 5.3 建议里程碑

| 阶段 | 目标周期 | 交付 |
|------|----------|------|
| M0 立项 | 2 周 | 类目预审沟通、数值表冻结、美术风格板 |
| M1 可玩白盒 | 6–8 周 | 单机/房间内完整一局（含 AI 背刺） |
| M2 内测 | +4 周 | 支付、分享、观战、数据埋点 |
| M3 提审上线 | +2–6 周（含审核） | 软著/版号路径按实际；过审后灰度 |

## 6. 技术架构粗估

### 6.1 客户端（微信小游戏）

| 选项 | 建议 | 理由 |
|------|------|------|
| **主推** | **Cocos Creator 3.x → 微信小游戏** | 2D 棋盘友好、团队人才多、包体与性能可控 |
| 备选 | Laya / Egret | 亦可；若团队已有积累可沿用 |
| 不建议首发 | Unity 转小游戏 | 包体与适配成本偏高，除非已有 Unity 资产 |

**客户端职责：** 棋盘渲染、合法着生成与展示、走子费预览、盟约/贿赂 UI、回放、分享卡片。

### 6.2 服务端

```
[微信小游戏客户端]
        | HTTPS / WebSocket
[接入层]  网关 · 登录鉴权（微信 code）· 限流
        |
[对局服务]  房间 · 回合状态机 · 合法着校验（权威在服务器）
[经济服务]  账户积分 · 本局作战/押金 · 充值发货 · 账本流水
[社交服务]  私聊求援 · 盟约状态 · 观战广播 · 分享归因
[AI 服务]   选座 · 走子决策 · 背刺时机 · 动机日志
[数据]      Redis（房间热状态）+ MySQL/PostgreSQL（账户/流水）
            + 对象存储（回放棋谱）
```

**关键原则：**

- **服务器权威校验**所有走子与结算；客户端只做表现。  
- 非法着在服务器拒绝；永不出现「客户端可作弊走子」。  
- 积分流水可审计（充值、消耗、罚没、退款）。

### 6.3 AI

| 层级 | MVP | 后期 |
|------|-----|------|
| 走子 | 启发式评估（子力、安全、走子费、将）+ 浅层搜索 | 可换增强搜索或轻量网络 |
| 社交 | 脚本化：何时求援/接受/背刺；参数可配 | 小模型生成动机文案 |
| 身份隐藏 | AI 延迟拟人化（思考 0.5–2s）、偶尔「次优」着法 | 行为画像混淆 |

**成本控制：** MVP 不对每步调用大模型；动机摘要用模板填空即可。

### 6.4 运维与安全

- 房间状态 Redis + 定时快照；断线重连 60s 内可回桌。  
- 反作弊：异常超高胜率、多开刷邀请、改包加速——基础检测。  
- 日志：对局 ID、经济流水、支付回调完整落库。

## 8. 合规注意

> 以下为产品侧检查清单，**不构成法律意见**；上线前须企业法务/合规顾问按最新微信与国家政策复核。

### 8.1 棋牌类目

- 微信小游戏「棋牌」类目通常要求企业主体，并按平台规则提交资质（软著、版号或平台当期认可材料等）。  
- 立项第一周即启动类目预沟通，避免做完再卡审。  
- 宣传文案避免「赌博」「押真金」等表述；本产品为**积分娱乐**，对外统一口径。

### 8.2 随机与概率

- 核心胜负应来自棋力与社交策略，而非抽卡开箱。  
- 若后续增加盲盒外观：需公示概率，符合平台与法规对随机道具的要求。  
- AI 座位随机须可审计（服务端种子），禁止前端可篡改。

### 8.3 虚拟货币 / 积分

- 积分仅本游戏内使用；**禁止逆向兑换人民币**；禁止官方渠道外的积分交易。  
- 充值走微信虚拟支付；未成年按防沉迷与支付限额执行。  
- 罚没、背刺均为游戏规则内积分转移，不包装为「投资收益」。

### 8.4 隐私与社交

- 微信登录最小化授权；隐私政策明示数据用途（对局、风控、支付）。  
- 私聊求援保留举报与违禁词过滤。  
- 观战弹幕用预设+过滤，降低人身攻击与广告风险。  
- 回放分享默认脱敏昵称选项。

### 8.5 内容与文化

- 三国题材注意历史人物形象尺度；避免血腥写实。  
- 「卧底/背刺」玩法文案向社交推理娱乐靠拢，避免宣扬欺诈价值观的过度擦边。

### 8.6 广告与分享

- 分享激励防刷（设备指纹、账号龄、异常集群）。  
- 不诱导分享至外挂群、不诱导私下交易积分。
