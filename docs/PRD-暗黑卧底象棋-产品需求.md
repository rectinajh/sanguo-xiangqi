### 一句话卖点

**三人对局，桌上必有一座 AI 卧底——每步烧积分、结盟押诚意、背刺罚没；终局揭晓谁是 AI，弱者也有戏唱。**

### 电梯稿（30 秒）

双人象棋一开局，高手碾压，弱方零 agency。我们把桌子做成「狼人杀 + 轻象棋」：三人（2 人 + 1 AI），走子要花钱，结盟要押诚意金，背刺被系统罚没；你不知道谁是 AI，也不知道盟友下一手会不会捅刀。省油打法与氪金打法都能赢。适合微信群分享、观战吐槽、终局截图传播。

## 2. 问题陈述

### 2.1 双人象棋实力碾压为何不好玩（消费场景）

| 现象 | 玩家感受 | 产品后果 |
|---|---|---|
| 等级差 ≥ 2 档 | 弱方开局 10 手内失去反击空间 | 秒退、挂机、拒玩 |
| 信息完全公开 | 「会就不会」一目了然 | 社交局变成公开处刑 |
| 单一胜负维度 | 只有将死/认输 | 弱方无法用经济、结盟、诈唬创造戏剧 |
| 复盘羞耻 | 被碾压的棋谱不愿分享 | 零传播钩子 |

**核心结论：** 消费向象棋的瓶颈不是「棋不够深」，而是 **实力差吞噬了弱方的决策权（agency）**。继续加深棋力只会加剧流失。

### 2.2 第三方如何引入「最大不确定性」

引入第三座（真人 or AI）后，局面从零和双人博弈变成 **不完全信息多边博弈**：

1. **身份不确定**：恰好一座是 AI 卧底；人类互猜、互坑。  
2. **意图不确定**：盟友是在帮你，还是在养刀？  
3. **经济不确定**：对方是真没分了，还是装穷诱你？  
4. **时机不确定**：背刺发生在中盘还是终局前一手？  
5. **叙事不确定**：终局揭晓卡把整局改写成「故事」——适合截图与群聊。

**设计原则：** 第三方不是「多一个对手」，而是 **不确定性发生器**。棋力差距被「谁可信 / 谁该背刺 / 积分够不够」稀释；弱方可以通过结盟、省油、诱导背刺参与戏剧，而不是只会挨打。

### 2.3 为何必须是 AI 卧底（MVP）

- 三人真人冷启动难凑桌；**2 人 + 1 AI** 是匹配刚需。  
- AI 提供可控的「假诚意 / 油费刺客 / 适时背刺」剧本，保证每局有戏。  
- 人类不知道 AI 坐哪一座 → 「猜谁是 AI」成为跨局传播主题。

## 3. 品类定位

### 3.1 坐标

```
        重推理 / 社交欺骗
              ▲
   狼人杀 · 太空狼          ★ 本产品（暗黑卧底象棋）
              │
   三国杀（轻量） ──────────┼────────── 传统象棋 / 围棋
              │                    重技能 / 深度
              ▼
           轻棋类休闲
```

| 对标 | 借什么 | 不借什么 |
|---|---|---|
| 狼人杀 | 身份猜忌、发言/结盟戏剧、终局揭晓传播 | 长夜晚、强依赖麦、纯投票无操作 |
| 太空狼（Among Us） | 任务（走子/经济）与杀机并行、短局 | 纯移动操作、无棋盘深度 |
| 三国杀轻量 | 身份牌感、背刺爽感、国风包袱 | 卡牌堆叠复杂度、长教学 |
| 传统象棋 | 国民认知、棋子语义 | 完整规则百科、长考文化 |

### 3.2 定位句

**暗黑社交推理为壳，轻象棋为骨，积分经济为血，AI 卧底为刀。**

目标用户：玩过狼人杀/三国杀、会一点象棋或不排斥棋盘的 18–35 微信用户；不追求职业棋力，追求「局内戏剧 + 好友局吐槽」。

## 4. 核心体验支柱

制作组所有功能取舍，用这四根柱子过筛。任一功能若撑不住至少一根柱子，砍掉或降级。

### 4.1 不确定性（Uncertainty）

- 桌上恰好 1 座 AI；UI 永不标出。  
- 盟约、求援私聊对局外不可见。  
- AI 行为有随机窗口，避免「第 12 手必背刺」被摸规律。

### 4.2 信息不对称（Asymmetric Info）

| 公开 | 私密 |
|---|---|
| 棋盘、行棋方、棋谱、各座作战积分与记分牌 | AI 身份 |
| 公开事件文案（「有人结盟了」「有人被罚没」— 可不露座位） | 盟约条款明文、求援私聊、未公开贿赂当事人 |

观战者看到公开层，**看不到** AI 身份与盟约当事人 → 适合弹幕猜身份。

### 4.3 经济压力（Economic Pressure）

- 每步合法着都有 `moveFee`；远途车贵、卒便宜。  
- 吃子赚分、被吃丢分；破产 = 出局。  
- 结盟要锁诚意积分；背刺被挑战则罚没。  
- **省油与氪金是两条合法打法**，不是「有钱必胜」。

### 4.4 戏剧揭晓（Dramatic Reveal）

- 终局强制播放揭晓卡：AI 是谁、背刺几次、动机摘要（模板填空）。  
- 一键生成分享图 / 小程序卡片。  
- 回放可跳到「背刺节点」与「AI 动机」节点。

## 5. 核心循环与局内流程

### 5.1 局外循环（产品）

```
打开小程序 → 快速匹配 / 好友房
    → 完整一局（含揭晓）
    → 分享终局卡 / 群聊讨论
    → 任务领积分 / 充值补给
    → 再开一局（D1/D7 回流）
```

### 5.2 局内流程（开局 → 中盘阴谋 → 背刺 → 终局）

```
匹配/好友房入座
  → 各扣「入座押金积分」+ 注入「作战积分」
  → 系统私下指定恰好 1 个 AI 座
  → 回合制走子：合法着扣 moveFee
  → 吃子：进攻方赚积分；被吃方丢部分积分 + 捕获罚金
  → 可选：秘密求援（私聊 + 锁诚意积分）→ 对方接受 → 盟约生效
  → 可选：疏火贿赂 BUY_PEACE（花积分买 N 步停火）
  → 背刺/违约 → 受害方发起挑战 → 诚意积分罚没给受害方
  → 出局（将死 / 破产付不起最低合法着）→ 击败方吞对方积分
  → 终局：揭 AI + 动机摘要 + 结算排名与赛季分
```

### 5.3 阶段节奏建议（制作向）

| 阶段 | 约手时 | 玩家应感到 | 系统侧重点 |
|---|---|---|---|
| 开局 | 1–8 手 | 摸身份、省油布局 | AI 装人；低烈度交火 |
| 中盘阴谋 | 9–25 手 | 求援、假盟友、积分吃紧 | 诚意/BUY_PEACE 高发；AI 假诚意窗口 |
| 背刺高潮 | 视局势 | 「被捅了」或「我捅了」 | 罚没动画；公开事件文案 |
| 终局 | 剩 1–2 座或时限 | 揭晓、排名、分享欲 | 揭晓卡强制完整播放一次 |

**单局目标时长：** 8–15 分钟（休闲局）；练习房可 0.5× 积分倍率缩短决策压力。

## 6. 系统需求

### 6.1 棋盘简化规则（轻象棋）

> 原则：**inspired by 三人象棋，不做规则百科。** 教学 ≤ 90 秒可上手。

**P0 必须落地：**

- 三方座位（红 / 黑 / 绿或等价国风色），标准简化三人布局（以工程现有棋规模块为准）。  
- 子力：将（帅）、车、马、炮、象/相、士、卒 — 走法贴近大众象棋认知；三人特有接触规则以「可执行简化表」锁定，冲突时本 PRD 简化优先。  
- 将死 / 无合法着且付不起最低 `moveFee` → 出局。  
- UI：点选棋子 → 高亮合法格 → 格旁显示预估 `moveFee`；余额不足的合法格灰显并提示「作战积分不足」。  
- **合法走子永远优先于烧积分** — 不存在「花积分走非法着」。

**非目标（棋规）：** 残局库、让子赛、完整古谱教学、职业级别判负细则。

### 6.2 积分经济

账户积分统一承载跨局资产；局内拆成：

| 池 | 说明 |
|---|---|
| 账户积分 | 可跨局；充值 / 任务 / 赛季奖励获得 |
| 入座押金 `seatStake` | 开局锁定；终局按规则退还/分成 |
| 作战积分 `playBalance` | 本局走子 / 诚意 / 贿赂消耗池 |
| 记分牌 | 吃子与击败产生的局内战绩分 |

**合规口径：** 积分为游戏内道具，**不可兑换现金、不可玩家间转赠现金化**；仅用于对局与装饰。

**走子费（示意，可热修）：** 与距离、子力相关；口播示例——卒走 1 格约 0.9 积分；马 distance=2 约 3 积分；车走 5 格约 7 积分。默认数值表沿用积分版 §2.9（`playBalanceInitial=200`、`earnestBond=10` 等），运营后台可覆盖。

**结算骨架：**

- 击败：击败方吞败方记分牌；押金按比例分给击败方与奖池。  
- 终局奖池：建议 70% 胜者 / 20% 积分第二 / 10% 系统。  
- 胜者押金全退；剩余作战积分退回账户。

### 6.3 结盟 / 诚意金

**状态机：**

```
待接受诚意 → 接受后盟约生效 | 拒绝/超时退诚意
生效 → 履约退还 | 违约 → 受害方挑战 → 罚没给受害方
```

**盟约条款（≥2 条可组合，P0）：** 例：`NO_CAPTURE_ALLY_KEY`（不吃盟友关键子）、`NO_ATTACK_GENERAL`（不攻帅）、可选 `NO_EXPOSE_BEFORE_END`（终局前不公开指控对方是 AI）。

默认每座同时 1 笔 Pending；作战积分 ≥ 阈值可并行最多 3 笔（多头试探 = 氪金向优势，但仍有罚没风险）。

### 6.4 AI 卧底

**身份：** 系统指定恰好一座；对人类 UI 与观战均不显示。

**P0 策略（规则+启发式，不大模型逐步推理）：**

| 策略 | 行为 |
|---|---|
| 装人 | 开局走子风格接近均值人类；偶发「犹豫式」低费着 |
| 假诚意 | 盟约履约约 8–12 手后吃盟友关键子或攻帅 |
| 油费刺客 | 用远途车威胁逼人类烧作战积分 |
| 收割 | 优先吃高记分子；对破产边缘人类施压 |
| 动机日志 | 关键决策写入模板字段，供终局摘要填空 |

**验收红线：** AI 不能「一眼假」（固定开局套路）也不能「永远碾压」。目标：人类猜对 AI 座的准确率落在 **45%–70%** 区间（软启动周报追踪）。

### 6.5 氪金 vs 性价比

| 路线 | 优势 | 典型动作 |
|---|---|---|
| **氪金（Whale）** | 积分多 → 敢走贵着、多线诚意、BUY_PEACE、中盘补给 | 节奏压迫、多头试探 |
| **性价比（F2P）** | 省油、诱敌烧分、精準背刺挑战、任务积分 | 低费布局、收钱背刺反制 |

**付费边界：** 不卖「必胜礼包」；可卖补给包（作战积分）与外观。付费只影响「敢走贵着 / 多结盟试探」，**不改变棋规合法性**。

礼包档位示意（元 → 积分）：与积分版一致的轻中重档；新用户赠送足够打完约 2 局。

### 6.6 远期可选轨道（非本版范围）

链上积分 / Token / 钱包：**仅备案为远期可选**，本版不做、不宣传、不进提审材料。消费版成功验证留存与付费后再评估合规与成本。

## 7. 暗黑游戏开发流程（制作人手册）

> 本章是本文档重点。按 **立项 → 原型 → 竖切 → 数值 → 包装 → 提审 → 软启动** 推进。  
> 每一阶段未过验收标准，**禁止进入下一阶段排期锁定**（可并行调研，不可并行「假装做完」）。

---

### Phase 0 — 立项与风险

**目标**  
对齐「我们在做社交推理游戏，不是在做象棋引擎」；写下杀项条件与预算锚点。

**产出物**

| 产出 | 负责人 | 说明 |
|---|---|---|
| 立项一页纸 | 制作人 | 卖点、用户、非目标、成功指标 |
| 风险登记册 | 制作人 + 发行 | 见下表；每条有 owner 与触发条件 |
| 预算锚点 | 制作人 | **推荐中档 85–110 万**（完整 MVP + 一次审核返修 + 中等投放） |
| 技术选型备忘 | 主程 | 小游戏优先；不建议首发 Unity 转小游戏 |

**风险登记（P0 必盯）**

| ID | 风险 | 触发信号 | 缓解 |
|---|---|---|---|
| R1 | 三人局仍不如双人好玩 | 纸面原型趣味分 ≤ 双人对照组 | 加诚意/背刺戏剧；或杀项 |
| R2 | 匹配冷启动 | 匹配超时 > 40s 占比高 | 强制 2+1AI；好友房 |
| R3 | 积分经济崩盘 | 「一步破产」或「只吃不走」刷屏 | 数值热修；日监控 |
| R4 | AI 一眼假 / 永远强 | 猜对率 >85% 或 <30% | 调策略权重与随机窗 |
| R5 | 提审/类目卡壳 | 驳回含棋牌/支付/隐私 | 预审清单；法务并行 |
| R6 | 象棋过重劝退狼人杀用户 | 新手局完成率 <40% | 再砍规则；加强引导 |

**验收标准**

- [ ] 全组能背诵一句话卖点与四根体验支柱  
- [ ] 风险册每条有 owner  
- [ ] 明确杀项条件：纸面阶段「三人趣味显著优于双人」未达成 → 停或改方向  
- [ ] 预算按中档立项，低/高档仅作情景分析

**常见翻车点**

- 立项写成「正统三人象棋 + 社交皮」，制作中又回到深度棋力。  
- 过早谈链上/Token，污染消费版叙事与提审材料。  
- 没有杀项条件，纸面不好玩仍硬开竖切烧钱。

---

### Phase 1 — 纸面 / 无美术原型（可玩性验证）

**目标**  
用最低成本验证：**三人局（含卧底规则）是否比双人象棋更好玩**，以及诚意/背刺是否产生「想再来一局」的戏剧。

**产出物**

| 产出 | 说明 |
|---|---|
| 纸面规则卡 v0.3 | ≤ 2 页；含简化棋规 + 积分筹码规则 + 结盟/背刺 |
| 主持人剧本 | AI 座由主持人暗骰；假诚意时机表 |
| 试玩记录表 | 每场：趣味 1–5、公平感、是否想再玩、猜 AI 是否正确、名言金句 |
| 对照组数据 | 同批用户先打或后打「简化双人象棋」各 ≥1 局 |
| Go/No-Go 纪要 | 制作人签字；决定是否进 Phase 2 |

**方法（强制执行）**

1. 招募 12–20 名目标用户（狼人杀/三国杀玩家为主，象棋爱好者 ≤30%）。  
2. 每人至少参与：**1 局双人对照组 + 1 局三人卧底局**（顺序对半交叉）。  
3. AI 用「人类主持 + 策略卡」扮演，不写代码。  
4. 积分用实体筹码或表格记账。  
5. 禁止在本阶段讨论立绘、皮肤、BGM。

**验收标准（硬门槛）**

- [ ] 三人局平均趣味分 **≥ 双人对照组 +0.7**（5 分制）  
- [ ] 「还想再玩一局」占比 ≥ 60%  
- [ ] 至少观察到 **3 次以上**自然发生的背刺戏剧（非主持人强行念剧本）  
- [ ] 新手在 **5 分钟内**能完成首次合法走子 + 一次求援尝试  
- [ ] 无「完全不懂在玩什么」的集体翻车（若有，先改规则再测）

**常见翻车点**

- 纸面规则写成百科，试玩变成教学会。  
- 主持人 AI 演得太戏精或太傻，污染结论。  
- 用象棋高手样本代替狼人杀用户，得出「还是双人有趣」的伪结论。  
- 没做对照组，只凭「感觉三人有意思」就开竖切。

---

### Phase 2 — 竖切 Demo（2 人 + 1 AI）

**目标**  
做出 **一条可玩竖切**：从入座到终局揭晓的完整闭环；验证联网同步、AI 座隐藏、诚意状态机、积分扣费在真机上的手感。

**产出物**

| 产出 | 说明 |
|---|---|
| 竖切包 | 微信开发者工具 / 真机可跑；好友房或本地双端 |
| 功能清单勾选 | 见下「竖切必含」 |
| 缺陷板 | P0/P1；P0 清零才能邀测 |
| 5 人狗粮报告 | 组内 + 好友；含崩溃、卡顿、规则歧义 |
| 竖切演示录像 | 15 分钟内含一次背刺 + 揭晓 |

**竖切必含（Scope Freeze）**

1. 2 人类 + 1 AI 开局（AI 座随机且对 UI 隐藏）  
2. 简化棋盘走子 + `moveFee` 预览与扣除  
3. 吃子计分与破产出局  
4. 诚意求援 → 盟约 → 违约罚没（至少 1 条条款可玩）  
5. AI：装人走子 + 假诚意背刺至少一种路径  
6. 终局揭晓卡（AI 是谁 + 简单动机一句）  
7. 基础断线重连（本局内）

**明确不做（竖切）**

支付、赛季、观战弹幕、精美美术、BUY_PEACE 全量、多条款盟约编辑器、回放分享图。

**验收标准**

- [ ] 非制作人员按引导可独立打完一局（主持人零干预）  
- [ ] 连续 10 局无阻塞性断局；崩溃率 <5%  
- [ ] AI 身份在局中零泄露（日志/UI/观战位均查）  
- [ ] 诚意状态机无「锁分吃掉不退」类经济事故  
- [ ] 揭晓卡播放完整，分享按钮可出占位图  

**常见翻车点**

- 竖切做成「象棋单机 + AI 对战」，社交欺骗全缺。  
- 为追美术进度拖垮竖切排期。  
- AI 用随机合法着，导致「卧底无剧本」。  
- 同步以客户端为准，出现双端棋面不一致。

### Phase 3 — 数值与反作弊

**目标**  
把「好玩」变成「可运营」：经济不崩、作弊难赚、AI 难度可调；所有关键参数可热修。

**产出物**

| 产出 | 说明 |
|---|---|
| 数值表 v1（可热修） | 走子费、吃子、押金、诚意、奖池、补给上限 |
| 仿真报告 | 脚本跑 ≥1 万局：破产率、局时长、AI 胜率、猜对率 |
| 反作弊方案 | 服务端权威、速率限制、积分流水审计、设备/实名防刷邀请 |
| 运营后台最小集 | 改数值、封号、查局回放元数据、看日活漏斗 |
| 监控看板 | 一步破产率、只吃不走率、匹配时长、支付成功率 |

**数值健康带（建议初始）**

| 指标 | 健康带 | 越界动作 |
|---|---|---|
| 中位局时长 | 8–15 分钟 | 调时限/费用/AI 侵略性 |
| 破产出局占比 | 10%–25% | 调 `playBalanceInitial` / moveFee |
| AI 胜率（非猜身份） | 25%–40% | 调启发式权重 |
| 人类猜对 AI 座 | 45%–70% | 调假诚意窗口与装人噪声 |
| 人均诚意发起/局 | 0.8–2.0 | 调 `earnestBond` 与引导 |

**反作弊 P0**

- 棋规与积分结算 **服务端权威**；客户端只预测展示。  
- 所有积分变动写流水（谁、为何、局 ID、前后余额）。  
- 邀请有礼：设备指纹 + 微信实名风险标签；异常集群人工审。  
- 禁止客户端改 `moveFee` / 隐身 AI 座号。

**验收标准**

- [ ] 热修数值 **无需发版** 可生效（配置下发）  
- [ ] 仿真无「无限刷分闭环」  
- [ ] 抽测 50 局流水账平（进出平衡）  
- [ ] 作弊用例（加速器、重放请求）至少挡下 P0 列表  

**常见翻车点**

- 数值写死在客户端。  
- 只调「手感」不跑仿真，上线首周经济崩。  
- 反作弊做成「外挂对抗幻想」，忽略刷邀请与积分流水。  
- AI 调参只看胜率，不看猜对率 → 扼杀传播点。

---

### Phase 4 — 美术 / 音效包装

**目标**  
在玩法已冻的前提下，用暗黑国风包装放大「阴谋感」与揭晓爽感；**不借包装掩盖玩法洞**。

**产出物**

| 产出 | 说明 |
|---|---|
| 视觉方向板 | 暗黑国风：烛影、面具、残局桌；避免萌化冲淡背刺 |
| UI 套件 | 棋盘、棋子、积分 HUD、盟约弹层、罚没特效、揭晓卡 |
| 音效包 | 走子、吃子、锁诚意、罚没、揭晓鼓点；短、脆、可关 |
| 分享图模板 | 终局卡 / 「我猜对了 AI」/ 「我被背刺了」 |
| 无障碍与弱网 | 省流量棋盘；色弱友好座位色 |

**验收标准**

- [ ] 包装前后 A/B：完成率不下降；分享点击率 ↑  
- [ ] 揭晓卡在真机 1 次播放可懂「谁是 AI」  
- [ ] 包体与首屏符合微信小游戏基线（按当年平台限额）  
- [ ] 关键音效可一键静音；不强制 BGM  

**常见翻车点**

- 立绘预算吞噬数值与 AI 工期。  
- 棋盘美化导致合法格难辨。  
- 揭晓动画过长（>8s）被狂点跳过 → 传播点丢失（应允许跳过但首局强制看完关键信息）。  
- 皮肤暗示身份（AI 座专用特效）→ 直接毁游戏。

---

### Phase 5 — 微信提审与合规

**目标**  
合法上架：类目、支付、隐私、内容、防沉迷（若适用）一次过或可控返修。

**产出物**

| 产出 | 说明 |
|---|---|
| 提审材料包 | 软著/主体/类目申请材料、隐私政策、用户协议、适龄提示 |
| 支付验收账号与用例 | 虚拟支付全流程；退款/补单预案 |
| 内容审查清单 | 文案、昵称过滤、分享图、AI 动机文案禁区 |
| 合规口径卡 | 「积分非货币、不可兑现」对外统一话术 |
| 返修记录 | 每次驳回原因 → 修改 → 复测 |

**检查清单（制作人打勾）**

- [ ] 无加密货币、钱包、链上字样出现在客户端与商店页  
- [ ] 积分消耗与获取展示清晰；支付点符合微信虚拟支付规范  
- [ ] 隐私政策可访问；微信登录权限最小化  
- [ ] 用户协议含公平游戏 / 反作弊 / 积分属性说明  
- [ ] 棋牌类目路径与法务当年意见一致（版号/无版号策略写明）  
- [ ] 分享卡片不夸大「赚钱」「稳赢」  

**验收标准**

- [ ] 提审通过或返修项全部关闭  
- [ ] 支付沙箱 + 真机各跑通  
- [ ] 法务签字的对外口径卡归档  

**常见翻车点**

- 用「链游」「Token」旧 PPT 误传给渠道。  
- 类目选错（休闲 vs 棋牌）导致反复驳回。  
- 邀请有礼被判定为不当激励。  
- 隐私政策外链 404 或与实际采集不符。

### Phase 6 — 软启动与传播钩子

**目标**  
小流量验证留存与传播；炸点放在「揭晓 + 背刺」，不是买量硬推。

**产出物**

| 产出 | 说明 |
|---|---|
| 软启动开关方案 | 地区/白名单/好友房优先 |
| 埋点字典 v1 | 匹配、走子、诚意、背刺、揭晓、分享、支付 |
| 传播钩子实装 | 终局揭晓卡、背刺瞬间分享、好友房卡片、邀请有礼 |
| 周复盘模板 | 漏斗 + 猜对率 + 经济监控 + Top 吐槽 |
| 放量门禁 | 达指标才开投放预算（中档投放假设内） |

**传播钩子（P0）**

1. **终局揭晓卡**：本局 AI 是 X，背刺 N 次 → 一键分享群。  
2. **背刺罚没动效截图**：受害者/凶手双视角文案。  
3. **好友房链接**：小程序卡片「来一局，桌上有卧底」。  
4. **猜对有彩**：猜对 AI 座的轻度积分彩头（防刷）。  
5. **观战**：公开层实时同步，适合群内一人开麦解说。

**软启动门禁（建议）**

| 指标 | 开门再放量 |
|---|---|
| 新手首局完成率 | ≥ 55% |
| D1 留存 | ≥ 25% |
| 分享率（局终产生分享/局） | ≥ 12% |
| 支付漏斗无阻塞 | 成功率达平台基线 |
| 严重事故 | 经济刷分 / AI 身份泄漏 = 0 |

**验收标准**

- [ ] 连续 14 天软启动无 P0 事故  
- [ ] 周复盘能定位「哪一手玩家流失」  
- [ ] 至少 2 个钩子的分享 UV 可归因  
- [ ] 达标后才启动中档投放预算；未达标只修产品不烧钱  

**常见翻车点**

- 软启动即全量买量，用钱掩盖留存洞。  
- 分享图只有品牌 Logo，没有「谁是 AI」信息。  
- 忽略群主/房主工具，导致好友局难开。  
- 把「猜对率过高」当成功（实际是 AI 太假）。

---

### 阶段门禁总表（制作人墙）

| 阶段 | 进入下一阶段的一句话门禁 |
|---|---|
| 0→1 | 卖点与杀项条件书面锁定 |
| 1→2 | 三人趣味显著优于双人对照组 |

| 5→6 | 提审通过 + 支付真机通过 |
| 6→放量 | 软启动门禁指标达标 |

## 8. MVP 边界与非目标

### 8.1 MVP 内（必须有）

| 模块 | 内容 |
|---|---|
| 账号 | 微信登录、基础资料、账户积分 |
| 对局 | 2 人 + 1 AI；简化三人象棋；合法格 + 走子费预览 |
| 经济 | 押金 / 作战积分 / 记分牌；吃子；击败吞分；破产；中盘补给 |
| 社交欺骗 | 诚意求援、盟约（≥2 条款）、背刺罚没、BUY_PEACE |
| AI | 假诚意 + 启发式走子 + 终局揭示与动机摘要 |
| 传播 | 揭晓卡分享、好友房、观战（公开层）、基础回放 |
| 运营 | 数值热修、流水、封禁、基础漏斗埋点 |
| 支付 | 微信虚拟支付礼包（补给/外观） |

### 8.2 非目标（本版明确不做）

- 加密货币、链上结算、钱包、NFT  
- 职业级象棋引擎 / 残局库 / 段位考试  
- 复杂大模型实时对话 AI（成本高；动机摘要用模板填空）  
- 跨服万人观战竞猜（合规敏感，后期评估）  
- 语音房间（可后期；MVP 用文本求援）  
- 三真人强制凑桌作为唯一模式（仅作延期）  
- Unity 重客户端首发

## 9. 成功指标

### 9.1 产品验证指标（软启动 4–8 周，中档投放前提下）

| 指标 | 目标假设 | 说明 |
|---|---|---|
| 新手首局完成率 | ≥ 55% | 教程+首局 |
| D1 / D7 留存 | ≥ 25% / ≥ 10% | 按行业休闲社交修正 |
| 局终分享率 | ≥ 12% | 含揭晓卡与背刺卡 |
| 人均日对局 | ≥ 1.6 | 好友局拉动 |
| 猜对 AI 座率 | 45%–70% | 传播与难度平衡带 |
| 付费转化（活跃） | ≥ 3% | 不靠必胜商品 |
| ARPU（付费用户） | 内部追踪 | 补给为主、外观为辅 |
| P0 事故 | 0 | 经济刷分、身份泄漏、支付资损 |

### 9.2 体验定性指标（每版本必看）

- 背刺事件发生率（局）  
- 诚意发起→接受→履约/罚没漏斗  
- 「省油胜局」占比（验证 F2P 可赢）  
- 匹配时长 P50 / P90  
- 举报：挂机、辱骂、恶意破产刷分  

### 9.3 北明星（North Star）

**每周「产生至少一次社交传播行为的对局数」**  
（分享揭晓 / 拉好友房 / 观战转参战）。比单纯 DAU 更能代表本品类健康度。
